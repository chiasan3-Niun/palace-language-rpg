# 待決問題與決策紀錄

這裡只記錄會影響後續開發的問題。沒有答案前，程式以最小、可替換的方式處理。

## 待決問題

### D-001：第一關的教材依據

- 問題：六書與漢字形體演變的題目要依哪一份國文教材或教師自編內容？
- 影響：答案、回饋文字與學習卡都會受影響。
- 目前處理：先使用佔位題，不把未核對的知識寫死。

### D-002：歷史與影視角色的界線

- 問題：是否保留現有角色名稱，或改為原創宮廷角色？
- 影響：版權、敘事語氣、角色設計與公開發布。
- 目前處理：開發框架保留角色 ID，實際名稱等待決定。

### D-003：失敗內容的適齡程度

- 問題：遊戲是否直接呈現賜死、刑罰與打入冷宮？
- 影響：校園使用、家長觀感、分級與教學安全。
- 目前處理：原型先用「任務失敗／重新推理」取代具體暴力描寫。

## 已採用的暫時決定

- 第一版只做單關原型，不同時實作十二關。
- 第一版不加入登入、雲端存檔與後端。
- 所有題目先保留來源與審查欄位，未核對內容不可標記為正式答案。
