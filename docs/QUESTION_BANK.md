# 《紫禁深宮·語文策》十二關題庫歸檔

## 題庫狀態

- 關卡數：12
- 每關題數：3
- 題目總數：36
- 題型配置：核心判斷、情境應用、解密驗證
- 目前狀態：專案自編，已完成 AI 內容初審
- 審查範圍：答案唯一性、干擾項合理性、回饋是否對應知識點、關卡情境一致性
- 備註：本題庫不宣稱對應特定出版社教材；正式教學仍應依使用學校課程調整用語

完整可供程式載入的資料位於：

`src/data/question-bank.js`

## 題庫用途

每一關的三題不是獨立考卷，而是對應遊戲流程：

1. 核心判斷：確認玩家掌握本關語文概念。
2. 情境應用：把概念放入宮廷事件。
3. 解密驗證：用語文判斷完成證物或機關。

目前前端仍使用每關第一題作為示範流程；下一階段可將第二、三題接到各關解密模組，形成「探索 → 判斷 → 解密」閉環。
