# 神武門第一關視覺素材包設計

## 目的

為《紫禁深宮·語文策》的第一關「神武門」建立可直接放入遊戲原型的完整視覺素材包，先驗證清代宮廷寫實風、角色辨識度、遊戲文字可讀性與資產命名方式，再擴充其餘十一關。

## 目標

- 完成第一關所需的背景、角色、道具與 UI 視覺素材。
- 所有素材使用原創角色，不直接重現《甄嬛傳》角色名稱或肖像。
- 保留女性秀女玩家角色設定。
- 採清代宮廷歷史寫實風，非動漫、非卡通、非塑膠 3D 風格。
- 圖像中的重要遊戲文字由遊戲介面疊加，不依賴 AI 生成文字。
- 所有最終素材放入目前專案資料夾的 `public/images/`。

## 非目標

- 這一輪不製作第二至第十二關素材。
- 不製作完整遊戲 UI 程式碼。
- 不製作音效、動畫、角色骨架或後端。
- 不把尚未確認的教材答案直接寫進圖片。

## 製作方案

### 方案 A：小型樣張

先做四項素材，確認風格後再擴充。風險最低，但無法立即驗證完整第一關畫面。

### 方案 B：第一關完整素材包（已選擇）

一次製作第一關所需的背景、三名角色、角色表情、道具與 UI 素材。進度最快，但若角色造型不理想，可能需要批次修訂。

### 方案 C：先做佔位畫面

先用佔位圖驗證介面，再製作正式素材。介面風險最低，但不能立即檢查正式美術效果。

## 視覺規格

### 共通風格

- 清代宮廷歷史寫實主義。
- 電影感構圖與高反差戲劇光。
- 朱紅、帝王黃、沉香木褐、雪景青灰為主要色系。
- 不使用動漫、卡通、現代服裝、現代建築、浮水印或簽名。
- 不在背景、立繪與道具中生成教學題目或介面文字。

### 尺寸與格式

| 類型 | 尺寸／比例 | 格式 |
|---|---|---|
| 背景 | 16:9；第一版以 1536×864 或更高解析度生成 | WebP；保留原始 PNG 備份 |
| 角色立繪 | 3:4；透明背景 | PNG；保留透明通道 |
| 道具 | 1:1；1024×1024 或更高 | WebP；需要去背者另存 PNG |
| UI 素材 | 1:1 或可伸縮橫幅 | PNG 或 SVG；文字不烘焙進圖像 |

## 目錄結構

```text
public/
  images/
    backgrounds/
    characters/
    items/
    ui/
```

每個素材同時保留一份生成原檔或高解析度 PNG，遊戲使用版本再轉成 WebP；不覆寫既有檔案，若需要重做則使用 `-v2`、`-v3` 後綴。

## 生成與驗收順序

1. 先生成兩張背景，確認 UI 留白與視線焦點。
2. 生成玩家秀女三種表情，確認服裝、髮飾與臉部一致。
3. 以同一組風格基準生成驗籍官與女官。
4. 生成四件道具，確認可在深色與淺色背景中辨識。
5. 生成 UI 素材，確認不含錯字與不可修改的文字。
6. 將素材放入專案目錄，做尺寸、透明通道、檔案可讀取性與畫面遮擋檢查。

## 驗收標準

- 資產編號與檔名一致。
- 角色服裝、髮型、年齡感與畫風在不同表情間保持一致。
- 背景不含明顯錯誤的 AI 文字、浮水印或現代物件。
- 角色立繪透明背景正常，手部與服飾沒有明顯變形。
- 背景可容納遊戲對話框與選項，不遮住主要敘事焦點。
- 所有素材都存在於專案資料夾，不能只留在生成工具的暫存路徑。

## 目前仍由作者確認的事項

- 驗籍官與女官的正式姓名，目前先使用職稱與資產 ID。
- 是否要在道具圖中出現可辨識的漢字；若需要，文字由遊戲 UI 疊加。
- 第一關失敗回饋是否使用「冷宮」意象，或只使用中性的任務失敗畫面。
