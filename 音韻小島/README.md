# 超難語音與音韻學群島

Niun的族語教學多媒體應用 製作。

使用 Vite 與 Three.js。執行 `npm install`、`npm run dev`；以 `npm run build` 產生 dist 網站。

階段性成果：12 座島嶼、206 項術語、24 篇小故事、概念搜尋、翻卡、選擇練習、英文朗讀、UDL 學習選項與本機錄音。錄音不會上傳。

內容限制：新增術語多數尚未補齊教材例子，英文音標目前只完成少數查核項目，其餘提供字典查詢入口。本版非完整課程驗收版；瀏覽器合成語音不等同真人 IPA 示範。

原始教材 PDF 與逐頁抽取文字不納入公開儲存庫。外部故事來源附於各故事內。
